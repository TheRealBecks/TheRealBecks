## BoxFerry 🚢

I'm the creator and maintainer of **BoxFerry**, an open-source tool for converting container
application definitions without silently hiding incompatible intent.

- **GitHub:** [Strukturpiloten/boxferry](https://github.com/Strukturpiloten/boxferry)
- **Website and documentation:** [boxferry.dev](https://boxferry.dev/)

BoxFerry currently works with Compose, Quadlet, and Podman definitions. It is accompanied by
specialized Rust libraries for understanding Compose, Quadlet, and Podman environments.
